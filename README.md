# Q/OS-CalQ – Downloads

Hier liegen die Installationsprogramme von **Q/OS-CalQ**, der kostenlosen Ausgabe von
Quonstruct OS für Leistungsverzeichnis und Aufmaß (Windows, derzeit Beta).

Aktuelle Version: **[Releases](../../releases/latest)**

Webseite, Anleitung und Datenschutz: <https://www.ucalq.com/qos-calq/>

Dieses Repository enthält keinen Quellcode. Das Programm sucht hier automatisch nach
Updates, wenn das in den Einstellungen eingeschaltet ist.
